Disaster Management Website (Frontend-Based)

A simple disaster management web application that simulates emergency response planning using basic Data Structures and Algorithms (DSA) concepts. This project does not use any backend or database — all operations are handled on the frontend.

Features

Disaster Input System
Users can report a disaster by specifying its type and priority level.

Automatic Resource Allocation
Based on the priority level, the system automatically assigns essential resources such as:

Food supplies

Water

Medical aid

Emergency support requirements

Zone Classification
Disasters are categorized into zones according to priority:

Red Zone – High priority disasters

Orange Zone – Medium priority disasters

Green Zone – Low priority disasters

Team Assignment
Disaster management teams are automatically allocated based on the severity of the situation.

Priority-Based Sorting (DSA Implementation)
The system uses basic sorting algorithms to organize and display disaster zones according to their priority levels.

Technologies Used

HTML

CSS

JavaScript

Data Structures & Sorting Algorithms (DSA concepts)

Purpose

This project demonstrates how fundamental DSA concepts like sorting and priority handling can be applied to a real-world scenario such as disaster management, using a simple frontend-only approach.
